# token-dashboard

A Claude Code mod: a live pane showing the session's token usage — totals, cache hit rate, cost, context window fill, rate limits, a per-request sparkline and a per-model breakdown.

Open it with `/tokens`.

## Install

The repository is private: you need access to it on GitHub, and GitHub set up on your computer.

```
/plugin install token-dashboard --marketplace mulbrix/claude-mods
```

Answer `y` to add the marketplace, then pick a scope.
